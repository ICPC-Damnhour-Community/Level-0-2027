# ICPC Damanhour Community - New Commers Training 2027

Welcome to the **New Commers Problem Solving Training**!  This repository is the starting point of your competitive programming journey, where you will learn the fundamentals of problem-solving and competitive programming using C++.

## 🚀 Get Started

All resources, weekly breakdowns, problem sheets, and training content are available in the **Wiki**.  
Explore: [ICPC Damanhour - New Commers Wiki](https://github.com/ICPC-Damnhour-Community/New-Commers-2027/wiki)

## 📅 Training Timeline

- **Sunday**: Study the topic of the week using the provided resources.
- **Monday**:Attend the session to understand the topic and learn how to apply it.
- **Friday,Saturday**: Live upsolve for the week’s problems.
- After each week, the new problem sheet is released, and the previous one is closed.
- **Weekly Contest**: Starting from **Week 2**, we will have a contest every 2 week to test your skills and track your progress.
